# Описание интерфейса проекта

## 1. Главная страница

Главная страница с интерактивным hero-блоком, описывающим функционал приложения для оценки риска тромбоэмболических осложнений по шкале Уэллса, представлена на рисунке 1. Страница содержит информационные карточки о клинической оценке, быстрой диагностике и точных результатах, секцию с описанием метода и клинических симптомов, а также блок с интерпретацией уровней риска (низкий, умеренный, высокий) с цветовой индикацией.

## 2. Навигационная панель

Навигационная панель с адаптивным меню, обеспечивающая доступ к основным разделам приложения и отображающая информацию о текущем пользователе, представлена на рисунке 2. Панель включает логотип приложения, пункты меню для главной страницы, списка симптомов и оценок, а также элементы управления авторизацией (вход/регистрация для неавторизованных пользователей, профиль и выход для авторизованных). Для мобильных устройств реализовано выдвижное меню (Offcanvas) с иконками для каждого пункта.

## 3. Хлебные крошки (Breadcrumbs)

Компонент навигационных хлебных крошек, отображающий иерархию страниц и обеспечивающий быструю навигацию по разделам приложения, представлен на рисунке 3.

## 4. Страница списка симптомов

Страница списка симптомов с поисковой строкой, сеткой карточек симптомов и функционалом добавления симптомов в черновик оценки для авторизованных пользователей, представлена на рисунке 4. Страница содержит поле поиска для фильтрации симптомов по названию, сетку карточек с изображениями, названиями, категориями и баллами по шкале Уэллса, а также кнопки добавления симптомов в черновик. Для авторизованных пользователей отображается плавающая кнопка черновика с индикатором количества добавленных симптомов.

## 5. Страница детального просмотра симптома

Страница детального просмотра симптома с полной информацией о симптоме, включая описание, факторы риска и баллы по шкале Уэллса, представлена на рисунке 5. Страница содержит крупное изображение симптома, подробное описание, информацию о факторах риска, отображение баллов с правильным склонением, кнопку добавления симптома в заявку для авторизованных пользователей, а также блок "Недавно просмотренные симптомы" в формате карусели для неавторизованных пользователей, отображающий до 6 последних просмотренных симптомов с исключением текущего.

## 6. Страница входа в систему

Страница входа в систему с формой аутентификации, включающей поля для имени пользователя и пароля, представлена на рисунке 6. Страница содержит карточку с иконкой безопасности, заголовком и описанием, форму с валидацией полей, индикатор загрузки во время процесса входа, обработку и отображение ошибок аутентификации, а также ссылку на страницу регистрации для новых пользователей.

## 7. Страница регистрации

Страница регистрации с расширенной формой создания нового аккаунта, включающей поля для имени пользователя, электронной почты, имени, фамилии и пароля с подтверждением, представлена на рисунке 7. Страница содержит карточку с иконкой регистрации, форму с валидацией обязательных полей и проверкой совпадения паролей, индикатор загрузки во время процесса регистрации, обработку и отображение ошибок, а также ссылку на страницу входа для существующих пользователей.

## 8. Страница личного кабинета

Страница личного кабинета с возможностью просмотра и редактирования профиля пользователя, представлена на рисунке 8. Страница содержит информацию о пользователе (имя пользователя, email, имя, фамилия), режим редактирования с кнопкой активации, форму с полями для обновления данных, кнопки сохранения и отмены изменений, индикатор загрузки во время обновления профиля, а также информацию о дате регистрации аккаунта.

## 9. Страница списка оценок

Страница списка оценок риска ТГВ/ТЭЛА с таблицей заявок, фильтрами по статусу и датам, а также функционалом управления для модераторов, представлена на рисунке 9. Страница содержит заголовок и описание (различаются для обычных пользователей и модераторов), секцию фильтров с выпадающим списком статусов и полями выбора дат формирования, дополнительный фильтр по создателю для модераторов, таблицу с колонками: ID, создатель (для модераторов), тема, статус с цветовой индикацией, уровень риска с цветовой индикацией (для модераторов), баллы, дата формирования, дата завершения (для модераторов), модератор (для модераторов), действия, кнопки "Завершить" и "Отклонить" для заявок со статусом "formed" (только для модераторов), модальное окно подтверждения действий, а также автоматическое обновление списка через short polling каждые 5 секунд.

## 10. Страница детального просмотра оценки

Страница детального просмотра оценки риска ТГВ/ТЭЛА с полной информацией о заявке, включая список симптомов с возможностью редактирования, представлена на рисунке 10. Страница содержит информацию о заявке (ID, тема, комментарий, статус, уровень риска, общий балл, даты), режим редактирования с возможностью изменения темы и комментария, таблицу симптомов с отображением названия, баллов и общего количества баллов для каждого симптома, возможность редактирования количества баллов для симптомов в черновике, кнопки удаления симптомов из заявки, кнопку формирования заявки для черновиков, кнопку удаления заявки с подтверждением, а также навигацию к списку оценок.

## 11. Блок недавно просмотренных симптомов

Блок недавно просмотренных симптомов в формате карусели, отображающий до 6 последних просмотренных симптомов для неавторизованных пользователей, представлен на рисунке 11. Блок содержит заголовок "Недавно просмотренные", карусель с навигационными кнопками и индикаторами, сетку из 4 карточек симптомов на каждом слайде, карточки с изображениями, названиями и баллами симптомов, hover-эффекты при наведении на карточки, а также адаптивный дизайн для различных размеров экранов. Блок скрывается для авторизованных пользователей и когда список пуст или содержит только текущий просматриваемый симптом.
