## 1️⃣ Установка и настройка ZeroTier

### Шаг 1: Установка ZeroTier

1. Перейдите на сайт: https://www.zerotier.com/download/
2. Скачайте и установите ZeroTier для вашей ОС (Windows/Mac/Linux)
3. После установки запустите ZeroTier

### Шаг 2: Создание ZeroTier сети

1. Зарегистрируйтесь на https://my.zerotier.com/ (или войдите, если уже есть аккаунт)
2. Перейдите в раздел **"Networks"** (Сети)
3. Нажмите **"Create A Network"** (Создать сеть)
4. Скопируйте **Network ID** (16-значный код, например: `a0b1c2d3e4f5g6h7`)

### Шаг 3: Подключение к сети

1. В приложении ZeroTier нажмите **"Join Network"** (Присоединиться к сети)
2. Вставьте **Network ID** и нажмите **"Join"**
3. Вернитесь на сайт my.zerotier.com
4. В списке устройств найдите ваше устройство и **поставьте галочку** (Authorize) - это даст доступ устройству к сети

### Шаг 4: Получение IP адреса

1. В приложении ZeroTier найдите вашу сеть
2. Под названием сети будет показан **IP адрес** (например: `10.147.17.5`)
3. **Скопируйте этот IP адрес** - он понадобится для настройки API

## 3️⃣ Настройка бэкенда (API сервера)

### ⚠️ ВАЖНО: По требованиям лабораторной работы бэкенд должен работать по HTTPS

1. **Бэкенд должен быть доступен по ZeroTier IP адресу**, а не только по `localhost`
2. **Бэкенд должен работать по HTTPS** (порт 443) для соответствия требованиям лабораторной работы
3. Бэкенд должен слушать на всех интерфейсах (`0.0.0.0`), а не только на `127.0.0.1`

### Настройка HTTPS на бэкенде

#### Для Django:

**1. Установите SSL сертификат (самоподписанный для тестирования):**
```bash
# Создайте самоподписанный сертификат
openssl req -x509 -newkey rsa:4096 -nodes -keyout key.pem -out cert.pem -days 365 -subj "/CN=10.174.203.183"
```

**2. Настройте Django для HTTPS:**
```python
# settings.py
ALLOWED_HOSTS = ['10.174.203.183', 'localhost', '127.0.0.1']
SECURE_SSL_REDIRECT = False  # Для dev режима
```

**3. Запустите Django с HTTPS:**
```bash
# Используя django-extensions
pip install django-extensions
python manage.py runserver_plus --cert-file cert.pem --key-file key.pem 0.0.0.0:443
```

**Или используйте nginx/gunicorn с SSL:**
```bash
gunicorn --bind 0.0.0.0:443 --keyfile key.pem --certfile cert.pem myproject.wsgi:application
```

#### Для Flask:

```python
from flask import Flask

app = Flask(__name__)

if __name__ == '__main__':
    # Запуск с HTTPS
    app.run(
        host='0.0.0.0',
        port=443,
        ssl_context=('cert.pem', 'key.pem')
    )
```

#### Для других фреймворков:

Используйте nginx как reverse proxy с SSL сертификатом.

### ⚠️ Важные замечания:

- **Самоподписанный сертификат**: Браузер будет показывать предупреждение о безопасности - это нормально для тестирования
- **Firewall**: Убедитесь, что порт 443 открыт в firewall
- **ZeroTier IP**: Используйте IP адрес из ZeroTier сети, не `localhost` или `127.0.0.1`

## 4️⃣ Настройка проекта (Frontend)

### Шаг 3: Настройка IP адреса в проекте

```typescript
// Замените 10.174.203.183 на ваш реальный ZeroTier IP
// ВАЖНО: По требованиям лабораторной работы должен использоваться HTTPS
```

**⚠️ ВАЖНО:**

## 5️⃣ Запуск Tauri приложения

### Шаг 1: Первый запуск (установка Rust)

При первом запуске Tauri автоматически установит Rust toolchain. Это может занять 5-10 минут.

```bash
npm run tauri:dev
```

**Что происходит:**
1. Устанавливается Rust (если еще не установлен)
2. Скачиваются зависимости Rust
3. Запускается Vite dev сервер
4. Собирается Tauri приложение
5. Открывается окно desktop приложения

### Шаг 2: Последующие запуски

После первого запуска команда будет работать быстрее:

```bash
npm run tauri:dev
```

### Возможные проблемы

**Проблема: "Rust not found"**
- Решение: Установите Rust вручную: https://www.rust-lang.org/tools/install

**Проблема: "Failed to build"**
- Решение: Убедитесь, что все зависимости установлены: `npm install`

**Проблема: "API недоступен"**
- Решение: Проверьте, что бэкенд запущен и доступен по ZeroTier IP

## 6️⃣ Проверка работы

### На десктопе (Tauri приложение)

1. Запустите `npm run tauri:dev`
2. В открывшемся окне проверьте:
   - ✅ Главная страница загружается
   - ✅ Список симптомов отображается
   - ✅ Поиск работает
   - ✅ Детальная страница открывается

### На мобильном устройстве

1. **Установите ZeroTier на телефон:**
   - iOS: App Store → ZeroTier One
   - Android: Google Play → ZeroTier One

2. **Подключите телефон к той же сети:**
   - Откройте приложение ZeroTier
   - Нажмите "+" → вставьте Network ID → Join
   - На сайте my.zerotier.com авторизуйте телефон (поставьте галочку)

3. **Соберите фронтенд для веб-версии:**
   ```bash
   # Переключитесь на main ветку для сборки веб-версии
   git checkout main
   npm run build
   ```
   
   Или если хотите использовать dev сервер Vite (для разработки):
   ```bash
   # В vite.config.ts нужно настроить host на ZeroTier IP
   # Запустите Vite с host на всех интерфейсах
   npm run dev -- --host 0.0.0.0
   ```

4. **Настройте веб-сервер для отдачи фронтенда:**
   
   **Вариант 1: Использование nginx (рекомендуется)**
   
   Установите nginx и создайте конфигурацию:
   ```nginx
   # /etc/nginx/sites-available/wells-method
   server {
       listen 443 ssl;
       server_name 10.174.203.183;  # Ваш ZeroTier IP
       
       ssl_certificate /path/to/cert.pem;
       ssl_certificate_key /path/to/key.pem;
       
       root /path/to/WEB-test-front/dist;
       index index.html;
       
       location / {
           try_files $uri $uri/ /index.html;
       }
       
       location /api {
           proxy_pass http://127.0.0.1:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   ```
   
   Активируйте конфигурацию:
   ```bash
   sudo ln -s /etc/nginx/sites-available/wells-method /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl reload nginx
   ```
   
   **Вариант 2: Использование встроенного сервера Python (для тестирования)**
   ```bash
   cd dist
   python -m http.server 443 --bind 0.0.0.0
   ```
   
   **Вариант 3: Использование Vite preview (для разработки)**
   ```bash
   # Соберите проект
   npm run build
   
   # Запустите preview с host на всех интерфейсах
   npm run preview -- --host 0.0.0.0 --port 443 --https
   ```

5. **Откройте в браузере телефона:**
   ```
   https://10.174.203.183:443
   ```
   (замените на ваш ZeroTier IP адрес)
   
   **⚠️ Важно:**
   - Используйте **HTTPS** (порт 443) по требованиям лабораторной работы
   - Браузер может показать предупреждение о самоподписанном сертификате - нажмите "Продолжить" или "Дополнительно" → "Перейти на сайт"
   - Убедитесь, что веб-сервер запущен и доступен по HTTPS

4. **Проверьте:**
   - ✅ Страницы загружаются
   - ✅ Интерфейс адаптивный (удобно на мобильном)
   - ✅ Поиск работает
   - ✅ API запросы проходят

## ❓ Частые вопросы

**Q: Как узнать свой ZeroTier IP?**
A: В приложении ZeroTier под названием сети будет показан IP адрес.

**Q: Бэкенд не доступен по ZeroTier IP**
A: Убедитесь, что бэкенд запущен на `0.0.0.0`, а не на `127.0.0.1`. Проверьте firewall.

**Q: Tauri не запускается**
A: Проверьте, что вы в ветке `lab_6_tauri` и все зависимости установлены.

**Q: API запросы не работают**
A: Проверьте IP адрес в `src/config/api.ts` и убедитесь, что бэкенд доступен по этому адресу.

**Q: Мобильный не может подключиться**
A: Убедитесь, что телефон авторизован в ZeroTier сети (галочка на сайте my.zerotier.com).
